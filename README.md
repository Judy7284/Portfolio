# Judy Chen — Portfolio

My personal portfolio website showcasing my software engineering, frontend development, and design work.

Built as an interactive pixel RPG-inspired interface with custom artwork, responsive layouts, and a focus on combining development with visual design.

## Built With

- React
- TypeScript
- Vite
- CSS

## Features

- Responsive layout across different screen sizes (the background being eaten up is a feature not a bug)
- Interactive tab-based navigation
- Custom pixel art environment and UI
- Animated background elements
- Projects and professional experience
- Design and creative work gallery
- Contact and social links

## Projects Featured

### Tumblr Comment Tracker

A full-stack application for retrieving Tumblr activity and organizing comments and nested reply threads with search, sorting, filtering, and pagination.

**Technologies:** React, Node.js, Express, OAuth

### Laesso

A 2D dungeon crawler where I worked as both a programmer and artist, creating scene transitions, cutscenes, dialogue systems, character animation, story elements, and level design.

**Technologies:** Unity, C#, Game Design, 2D Art

### CloverShelf

An Android application for organizing personal book collections with local storage, search, custom categories, reading-status filters, notes, and progress tracking.

**Technologies:** Java, Android, Room, SQLite
